### Typography

All text elements inherit from a consistent design system:

**Font Family**: Inter (system font, web-safe)

**Text Styles Identified**:
- **Manifesto Label**: MANIFESTO 01.0 (uppercase, secondary green)
- **Hero Heading**: Large serif/display style (dark green)
- **Section Headings**: "La Nostra Missione", "Il Ciclo della Sostenibilità", etc. (primary green, bold)
- **Body Text**: Regular weight, 16px equivalent (gray)
- **Stat Numbers**: Large display numbers (white on colored backgrounds)
- **Stat Labels**: Uppercase, smaller (teal/mint text)
- **Step Numbers**: 01, 02, 03 (large, branded green)
- **Quote Text**: Italicized, medium-dark green

### Component Patterns

1. **Stat Cards**: 
   - Colored backgrounds (mint/teal palette)

2. **Step Cards**:
   - Numbered indicators (01, 02, 03)

3. **Feature Pillars** (in Mission section):

   - Description text

4. **CTA Blocks**:
   - Colored background (primary brand color)
