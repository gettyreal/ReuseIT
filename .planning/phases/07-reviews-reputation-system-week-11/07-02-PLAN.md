<task type="auto">
  <name>task 1: Implement ReviewService with validation, atomicity, and denormalization</name>
  <files>src/Services/ReviewService.php</files>
  <action>Create `ReviewService` with constructor injection for `PDO`, `ReviewRepository`, `BookingRepository`, `UserRepository`, and `RateLimitService`.
Implement methods:
- `submitReview(int $bookingId, int $reviewerId, int $rating, ?string $comment): array`
  - Validate: booking exists and status is 'completed' (not pending/confirmed/cancelled).
  - Validate: reviewer is participant in booking (buyer or seller, not third party).
  - Validate: no existing review for this booking (findByBookingId returns null).
  - Check rate limit: isReviewLimited($reviewerId) returns false (allow 1 per 24 hrs).
  - Validate rating: 1-5 via Rating value object.
  - Validate comment: if provided, max 500 chars, plain text only (no HTML/markdown).
  - Begin transaction.
  - Get reviewed_user_id (opposite participant: if reviewer is buyer, reviewed is seller, etc).
  - Insert review via ReviewRepository.create().
  - Recalculate reviewed_user's avg_rating: SELECT AVG(rating) FROM reviews WHERE reviewed_user_id = ? AND deleted_at IS NULL.
  - Recalculate reviewed_user's total_reviews: SELECT COUNT(*) FROM reviews WHERE reviewed_user_id = ? AND deleted_at IS NULL.
  - Update users table: SET avg_rating = ?, total_reviews = ? WHERE id = ? in same transaction.
  - Record rate limit event: recordReviewSubmission($reviewerId).
  - Commit and return review record with updated user stats.
- `getUserReviews(int $userId, int $limit, int $offset): array`
  - Delegate to ReviewRepository.findByUserId() (newest-first, soft-delete filtered).
  - Return array of review records with reviewer metadata.
- `getUserStats(int $userId): array`
  - Return {avg_rating, total_reviews, distribution: {5: count, 4: count, 3: count, 2: count, 1: count}}.
  - Query users.avg_rating and users.total_reviews.
  - Query distribution via SELECT rating, COUNT(*) FROM reviews WHERE reviewed_user_id = ? AND deleted_at IS NULL GROUP BY rating.

All operations use prepared statements and transactions for atomicity. Throw InvalidArgumentException for validation failures, LogicException for non-recoverable errors.</action>
