<task type="auto">
  <name>task 1: Implement ReviewController with REST endpoints for submission and retrieval</name>
  <files>src/Controllers/ReviewController.php</files>
  <action>Create `ReviewController` with constructor injection for `ReviewService` and `BookingRepository`.
Implement public methods (HTTP endpoints):

1) `submitReview()` — POST /api/reviews
   - Extract from request body: booking_id (int, required), rating (int 1-5, required), comment (string, optional, max 500 chars).
   - Verify authentication: user must be logged in. Get reviewer_id from session.
   - Call ReviewService.submitReview(booking_id, reviewer_id, rating, comment).
   - On success: return 201 Created with review record {id, reviewer_id, reviewed_user_id, booking_id, rating, comment, created_at, reviewer: {name, avatar_url}}.
   - On validation failure: return 400 Bad Request with error message (e.g., "Booking not completed" / "Rate limit exceeded" / "Invalid rating").
   - On authorization failure: return 403 Forbidden.
   - Use try-catch to catch service exceptions and map to HTTP responses.

2) `getReviewsByUser()` — GET /api/reviews/user/:id
   - Extract from query params: limit (default 10, max 100), offset (default 0).
   - No authentication required (public endpoint).
   - Call ReviewService.getUserReviews(id, limit, offset).
   - Return 200 with array of reviews {id, reviewer: {id, name, avatar_url}, rating, comment, created_at, comment_preview, comment_truncated}.
   - Comment preview: first 100 chars if comment length > 100.

3) `getUserStats()` — GET /api/users/:id/stats
   - Extract path param: id (user id).
   - No authentication required.
   - Call ReviewService.getUserStats(id).
   - Return 200 with {avg_rating, total_reviews, distribution: {5: count, 4: count, 3: count, 2: count, 1: count}}.
   - If no reviews, return avg_rating: null, total_reviews: 0, distribution: {all: 0}.

All endpoints return standard response envelope {status, data, message}.</action>

    <automated>php -l src/Controllers/ReviewController.php && rg -n "submitReview|getReviewsByUser|getUserStats|201|400|403|ReviewService" src/Controllers/ReviewController.php</automated>
    <manual>Verify: submitReview enforces authentication, returns 400 on invalid rating, maps ReviewService exceptions to HTTP status codes.</manual>
  </verify>
  <done>ReviewController exposes 3 REST endpoints with proper HTTP status codes and error handling.</done>
</task>
