# Phase 10 Plan 03: Reviews Display & Reputation System

**Goal:** Implement reviews section on profile page showing all reviews for a user with ratings, comments, sorting options, and rating breakdown visualization.

## Dependencies

- **Phase 10 Plan 01:** Profile Display (profile.js must exist with showProfile function)
- **Phase 10 Plan 02:** Profile Editing (completes while this plan executes in parallel Wave 2)
- **Available from Phase 9:** Component library for cards, spinners, utility classes

## Requirements Addressed

- **FE-REV-02:** User reviews list on profile
- **FE-REV-03:** Review display with ratings breakdown

## Implementation Summary

This plan adds a reviews section to the profile page that:

1. Displays reviews for the user in a paginated list (10 per page)
2. Shows review details: star rating, reviewer name, review text, item reviewed, date
3. Provides client-side sorting: newest first (default), highest rated, oldest first
4. Shows rating breakdown: distribution of 5-star, 4-star, 3-star, 2-star, 1-star reviews
5. Loads more reviews on demand with "Load More" button
6. Handles loading states while fetching reviews

## User Decision References

From CONTEXT.md:
- Standard review list format (not card-based)
- Standard review details per review: rating stars, reviewer name, review text, item being reviewed, transaction date
- User-selectable review sort: newest first (default), highest rated first, oldest first
- Rating summary shows average rating + review count

## Tasks

### Task 1: Implement reviews API fetch with pagination

**What:** Load reviews from backend API with pagination support

**How:**
1. Create async loadUserReviews(userId, page = 1) function that:
   - Calls GET /api/v1/users/{userId}/reviews?page={page}&limit=10
   - Assumes response format: { reviews: [...], total, page, hasMore }
   - Stores reviews in state variable
   - Tracks currentPage for pagination
2. Display "Load More" button if hasMore is true
3. Append new reviews to list (not replace) on pagination
4. Handle errors: show error message, offer retry

**Acceptance Criteria:**
- First page of reviews loads on profile init
- Returns reviews array with rating, reviewer_name, review_text, item_name, created_at
- "Load More" button shows when more reviews available
- Clicking Load More fetches next page and appends to list
- Network errors show friendly message
- Loading state prevents duplicate requests

### Task 2: Create review list item HTML structure

**What:** Define review item DOM structure for rendering reviews

**How:**
1. Create review item HTML template (not card-based per user decision):
   ```html
   <div class="review-item">
     <div class="review-header">
       <div class="review-stars">{renderStars(rating)}</div>
       <div class="review-meta">
         <div class="review-author">{reviewer_name}</div>
         <div class="review-date">{formatted_date}</div>
       </div>
     </div>
     <div class="review-text">{review_text}</div>
     <div class="review-footer">
       <span class="review-item-name">Item: {item_name}</span>
     </div>
   </div>
   ```
2. Create renderStars(rating) helper: converts 1-5 number to star display (⭐⭐⭐...)
3. Create formatDate(created_at) helper: converts ISO date to "May 10, 2026"

**Acceptance Criteria:**
- Review structure includes all required fields
- Stars rendered as visual indicator (☆ or ⭐)
- Reviewer name and date displayed
- Item name shown at bottom
- Review text wraps correctly

---

### Task 3: Implement review sorting (client-side)

**What:** Add dropdown to sort reviews by newest/highest-rated/oldest

**How:**
1. Create .reviews-header section with:
   - Heading: "Reviews ({count})"
   - Select dropdown with options:
     - "Newest First" (default)
     - "Highest Rated First"
     - "Oldest First"
2. Create sortReviews(reviews, sortType) function that:
   - If 'newest': sort by created_at DESC
   - If 'highest': sort by rating DESC
   - If 'oldest': sort by created_at ASC
   - Does NOT modify original array (spread or slice first)
3. Attach change listener to dropdown:
   - Call sortReviews(reviews, selectedValue)
   - Re-render review list with sorted reviews
   - Reset to page 1 (don't keep Load More state)

**Acceptance Criteria:**
- Dropdown visible at top of reviews section
- Default sort is "Newest First"
- Changing sort re-renders list in correct order
- Sort is client-side only (no API call needed)
- All reviews visible (sorting doesn't reload, sorts in-memory)

---

### Task 4: Implement rating breakdown visualization

**What:** Show distribution of ratings (e.g., "45% 5-star, 30% 4-star, etc.")

**How:**
1. Create renderRatingBreakdown(reviews) function that:
   - Count reviews by star rating: counts[5], counts[4], counts[3], counts[2], counts[1]
   - Calculate percentages: (count / total) * 100
   - Return HTML with bar chart visualization
2. HTML structure for each rating row:
   ```html
   <div class="rating-row">
     <span class="rating-label">5⭐</span>
     <div class="rating-bar" style="width: {percent}%"></div>
     <span class="rating-percent">{percent}%</span>
   </div>
   ```
3. Display above review list in .rating-breakdown section
4. Show total review count: "from X reviews"

**Acceptance Criteria:**
- Breakdown shows all 5 rating levels (5, 4, 3, 2, 1 stars)
- Bar widths proportional to percentage
- Percentages calculated correctly
- Displays above review list
- Uses Phase 9 design tokens for colors

---

### Task 5: Implement average rating display

**What:** Show rating summary at top of reviews section

**How:**
1. Create renderRatingSummary(reviews, user) function that:
   - Calculate average: sum of ratings / count
   - Round to 1 decimal (e.g., "4.8")
   - Create HTML:
   ```html
   <div class="rating-summary">
     <div class="rating-value">{avgRating}</div>
     <div class="rating-stars">{renderStars(avgRating)}</div>
     <div class="rating-count">from {reviews.length} reviews</div>
   </div>
   ```
2. Display prominently above breakdown
3. Update dynamically when new reviews loaded

**Acceptance Criteria:**
- Average rating displays with 1 decimal place
- Stars show rounded rating (e.g., 4.8 ≈ ⭐⭐⭐⭐☆)
- Review count accurate
- Updates when Load More adds reviews
- Prominent positioning on page
